# Chính sách bảo mật

> 🌐 Ngôn ngữ: [English](SECURITY.md) · **Tiếng Việt**

Không công khai token, credential, private URL, SSH key, model artifact riêng tư hoặc dữ liệu nhạy cảm trong issue, discussion hay pull request.

Nếu phát hiện vấn đề bảo mật cần xử lý riêng, hãy liên hệ `i.am@dangkhoa.dev` với mô tả tối thiểu có thể tái lập. Không gửi secret thật nếu không cần thiết.

Các vấn đề về model behavior/quality không có tác động bảo mật nên dùng issue tracker thông thường.

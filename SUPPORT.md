# Support

> 🌐 Language: **English** · [Tiếng Việt](SUPPORT.vi.md)
## Questions and usage help

For reproducible usage questions, first review:

- [`README.md`](../README.md)
- [`docs/architecture.md`](../docs/architecture.md)
- [`docs/inference-guide.md`](../docs/inference-guide.md)
- [`docs/limitations.md`](../docs/limitations.md)

If the documentation does not resolve the problem, open a GitHub issue using the appropriate template.

## Bug reports

Include the exact commit, environment, TPU topology, resolution, seed(s), command, relevant logs, and expected/actual behavior.

Do not include credentials or private model/data URLs in issues.

## Security reports

Use [`SECURITY.md`](SECURITY.md), not a public issue.

## Upstream model questions

Questions about original Mage-Flow training, architecture research, or upstream model policy may belong in the Microsoft Mage project rather than this conversion/runtime repository.

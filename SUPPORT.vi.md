# Hỗ trợ

> 🌐 Ngôn ngữ: [English](SUPPORT.md) · **Tiếng Việt**

Repository hỗ trợ các vấn đề có thể tái lập liên quan tới runtime JAX/Keras, TPU orchestration, artifact contract, test, tài liệu và packaging của dự án này.

Khi báo lỗi, cung cấp commit/tag, platform, accelerator, JAX/Keras versions, topology, resolution, lệnh tái lập và log đã loại bỏ secret.

Các yêu cầu liên quan upstream training, quyền cấp phép của upstream weights hoặc dịch vụ inference được quản lý bên ngoài repository này nằm ngoài phạm vi hỗ trợ.
